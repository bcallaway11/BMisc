# makeBalancedPanel

Legacy version of \`make_balanced_panel\`, please use that function name
going forward, though this will still work for now.

## Usage

``` r
makeBalancedPanel(data, idname, tname)
```

## Arguments

- data:

  data.frame (or data.table) used in function

- idname:

  unique id

- tname:

  time period name
