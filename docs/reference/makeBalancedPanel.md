# makeBalancedPanel

Legacy version of \`make_balanced_panel\`, please use that function name
going forward, though this will still work for now.

## Usage

``` r
makeBalancedPanel(data, idname, tname, return_data.table = FALSE)
```

## Arguments

- data:

  data.frame used in function

- idname:

  unique id

- tname:

  time period name

- return_data.table:

  if TRUE, make_balanced_panel will return a data.table rather than a
  data.frame. Default is FALSE.
